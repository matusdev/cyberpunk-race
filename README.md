# NIGHT CITY RUSH

Street racing in Night City: 4, 6 or 8 cars, three laps through seven districts, traffic both ways,
a drive-through tuning garage next to the start line, and the 98.7 Body Heat Radio playing while you race.

Three.js + TypeScript (Vite). The same build runs in a browser and, wrapped with Capacitor, as an Android app.
All 3D models are generated by Blender scripts in [`blender/`](blender/README.md); textures and sounds are CC0
(see [`public/CREDITS.md`](public/CREDITS.md)).

## Run

```bash
npm install
npm run dev          # http://localhost:5180
npm run build        # web build in dist/ (static files, host anywhere)
npm run preview      # serve dist/ locally
```

Debug URLs: `/?race` jumps straight onto the grid with your last garage car, `/?race&auto` lets the AI drive it,
`&car=type66` picks a car, `&laps=1` sets the laps.

## Android

Requirements: JDK 21 and the Android SDK (Android Studio installs both).

```bash
npm run android:sync          # build + copy dist/ into android/
npm run android:apk           # debug APK: android/app/build/outputs/apk/debug/app-debug.apk
npx cap open android          # or open the project in Android Studio
```

The app runs fullscreen held sideways or upright (the HUD, touch pads, garage and race camera have a portrait
layout and follow a rotation at any time), keeps the screen on, autoplays the radio, and maps the hardware
Back button to pause / back. Icon and splash are rendered by `scripts/icon/make.mjs` and `scripts/icon/splash.mjs`.

## Controls

| | PC | Gamepad | Phone |
|---|---|---|---|
| Steer | A / D, ← → | left stick | tilt (or ◀ ▶ buttons) |
| Gas / brake + reverse | W / S, ↑ ↓ | RT / LT | GAS / BRAKE pedals |
| Drift (handbrake) | Space | A / RB | DRIFT |
| Nitro | Shift / N | B / LB | NOS |
| Camera | C | Y | Settings |
| Reset car | R | X | — |
| Next song | M | Back | — |
| Pause | Esc / P | Start | II button, Back |

Tilt: hold the phone like a wheel or flat — the game calibrates the centre when the race starts,
and Settings has a CALIBRATE button and a sensitivity slider. AUTO GAS is available for one-handed play.

## Flow

* **Menu** — the key art as a 2.5D scene: a depth map (made offline with Depth Anything V2) drives a parallax
  effect, so the car, the ring road and the skyline slide against each other with the mouse (or phone tilt), with
  rain and slowly breathing neon.
* **Garage** — its own 3D scene (garage.glb): the tuning hall with a gate at each end; the city key art is seen only
  through the gates. The car stands still, the camera starts at a three-quarter angle — drag to walk round it, wheel /
  pinch to zoom. The scene is pre-built in the background while the menu is up (a loader covers it if you are faster),
  so it opens without hitches. START RACE cuts to the race.
* **Race** — a race loader covers the set-up (the event card, your car, the circuit map lit as cars, traffic, shaders
  and sounds come in); then on the grid behind the rivals, the camera sweeps round the car during the countdown and
  settles into the chase view at GO.

## Gameplay

* **Circuit**: 6.2 km — Downtown boulevard → Kabuki market street → megabuilding tunnel → elevated expressway →
  Charter Hill park (a crest you can fly off) → docks → Japantown. 1–5 laps, 3 by default (≈5 minutes).
  4, 6 or 8 racers (Settings / pre-race).
* **Shortcuts**: the covered market hall (narrow, crates) and a dirt trail through the park (grass is slippery).
* **Traffic** drives in both directions and ignores the race (the street around the grid is closed until the start).
  Traffic has real weight (a 1 t city car up to a 7 t truck): hits are inelastic rigid-body impulses, a hit car lurches,
  slews round and scrubs to a stop instead of flying off; a glancing touch nudges you, rear-ending costs real speed,
  a head-on hurts the most, but one hit never takes more than half of your speed.
* **Car feel**: the body rides a sprung suspension on four contact patches — it squats under acceleration, dives
  under braking, rolls in corners, and a curb lifts one corner first.
* **Nitro** (blue flames from the tailpipes) refills from drifting, airtime, and near misses (oncoming traffic gives more).
* **Slow motion** on big crashes, long jumps, very close oncoming misses and the finish line — the radio slows down
  and drops in pitch with it.
* **Street clutter** (cones, barrels, crates, bins, benches) gets knocked flying; street lamps bend over and go dark.
  Trees, bus stops, booths, fences, market stalls and other solid furniture are hard obstacles.
* **Traffic drivers** brake for racers and wrecks ahead (brake lights, nose dive), dodge oncoming racers, and after a
  short wait drive slowly round a car that blocks the lane.
* **Garage**: fan recreations of four Cyberpunk 2077 cars — Quadra Turbo-R V-Tech, Quadra Type-66 Avenger,
  Rayfield Caliburn, Mizutani Shion MZ2 — paint, window tint, eight rim styles + colour, two body kits,
  three spoilers, underglow and accent neon, and a performance budget (engine, turbo, tyres, nitro, weight)
  that grows with your career level. Rivals get random builds with the same budget.
* **Career**: XP, levels and eddies for every finish; best lap / best race and stats on the CAREER screen.
* **Sound**: recorded engine RPM loops (crossfaded on/off throttle, re-voiced per car), turbo, blow-off, backfires,
  tyres, wet spray, wind, impacts, district ambience — all CC0, see `public/sfx/README.md`.
* **Music**: `public/music/playlist.json` — a random track starts with the race, then the playlist continues in order.
  `menu.mp3` plays in the menus.

## Code map

```
src/
  core/      math, input (keys, gamepad, touch, tilt), settings, GLB loading + material taming
  world/     path.ts (road spline + frames), trackdef.ts (the circuit), network.ts (corridors, junctions),
             roadmesh.ts, city.ts (building layout), buildings.ts, kitcity.ts (modelled towers, BatchedMesh),
             landmarks.ts (corp tower, ring road, holograms, AVs, chevrons, start arch),
             terrain.ts (park, ground, water),
             props.ts (instanced props + culling), debris.ts (knockable clutter), lighting.ts, world.ts
  vehicle/   specs.ts (cars, tuning), physics.ts (arcade model + sprung body, per-wheel contacts),
             collide.ts (SAT + impulses), ai.ts,
             traffic.ts, carview.ts (GLB car assembly, LOD, customisation), trafficview.ts
  race/      race.ts — grid, countdown, fixed 120 Hz simulation, contacts, laps, standings, events
  game/      game.ts (state machine), menuscene.ts (parallax key art), garagescene.ts, session.ts, camera.ts,
             slowmo.ts, career.ts
  render/    shaders (wet road + planar reflection, buildings, facades, walls, sky), post-processing
             (a NaN guard ahead of the bloom: one bad pixel would black out the frame), glows, particles,
             textures
  audio/     radio + sample-based car sound and ambience
  ui/        menus, garage, race loader, HUD, styles
scripts/     sim.ts (headless race, `node scripts/sim.ts 3 0.5`), traffic-react.ts (traffic braking / passing check),
             track/city reports, flow.mjs (scripted browser runs + screenshots)
blender/     model generators (cars, wheels, traffic, AV, props, city kit, garage) — see blender/README.md
```

The race logic has no rendering dependency, so `node scripts/sim.ts [laps] [traffic]` runs a full race with
the AI driving every car — handy after changing physics, AI or the track.

## Notes

The radio tracks in `public/music` come from the Cyberpunk 2077 soundtrack archive you provided, and the cars are fan
recreations of Cyberpunk 2077 designs. That is fine for a private hobby build, but don't publish the APK or the site
with them — swap in music you have the rights to.
