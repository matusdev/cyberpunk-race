## Notes on the generated / special texture files

- Normal maps (`*_nrm.jpg`) use the OpenGL convention (+Y = green up), which matches the Three.js default `normalScale (1, 1)`. `*_rgh` = roughness, `*_ao` = ambient occlusion, `*_mtl` = metalness (greyscale). All are 1024×1024 and tileable.
- `puddles_mask.png`: white = standing water (about 35 % coverage, soft edges); dark grey 0–0.25 = damp asphalt between puddles. Tileable. Use it to lower roughness / blend in reflections and `rain_ripple`.
- `rain_ripple.png` (RGBA, tileable, 70 drops): R,G = ripple direction from the drop centre (×2−1), B = radial falloff (1 at the centre → 0 at the edge, 0 = no drop), A = per-drop random time offset. Shader idea: `t = fract(time*rate + A); ring = sin((B - 1.0 + t)*K) * B * (1.0 - t); normal.xy += (RG*2-1) * ring`.
- `rain_normal.png`: one static frame of procedural ripple rings as an OpenGL normal map, for cheap use without animation.
